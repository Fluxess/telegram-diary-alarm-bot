# Telegram Personal Diary & Alarm Bot ⏰📖

Современный и стильный бот для ведения личного дневника, списка дел и умного будильника на телефоне.

## 🚀 Возможности
- ⏰ **Умный будильник дел**:
  - Настойчивый режим (Nagging): бот повторяет уведомление со звуком каждые 45 секунд, пока задача не будет выполнена или отложена на +5 / +15 минут.
  - 📲 **Синхронизация с телефоном**: создание `.ics` файлов для прямого импорта в системный календарь/будильник iOS/Android и кнопка добавления в 1 клик в Google Calendar.
- 📖 **Дневник мыслей и настроения**:
  - Трекер эмоций (🔥 😊 😐 😴 🌧️ 🤯).
  - Заметки и итоги дня.
  - Практика благодарности.
- 📱 **Telegram Mini App (Web App)**:
  - Современный UI в тёмной теме прямо внутри Telegram.
  - Просмотр списка задач, чекбоксы и карточки дневника.
- 🌍 **Поддержка часовых поясов**:
  - Выбор часового пояса прямо в меню (Москва, Екатеринбург, Новосибирск и др. или произвольный IANA-пояс).

---

## 🛠️ Запуск проекта

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите бота:
```bash
python bot.py
```
